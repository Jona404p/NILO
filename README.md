# NILO

Base técnica de NILO construida con Node.js, Next.js App Router, React y TypeScript.

## Requisitos

- Node.js `>=20.9.0`
- npm

## Desarrollo local

```bash
npm ci
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

## Comandos

```bash
npm run lint
npm run build
npm run start
```
